# Work Plan for Claude Code

Work Plan for Claude Code (`xnervwang.claude-code-extras`) is now published as [Claude Code Plus](https://marketplace.visualstudio.com/items?itemName=xnervwang.claude-code-plus) (`xnervwang.claude-code-plus`). Updating this extension installs Claude Code Plus, which takes over the settings, pins and session colors. You can then uninstall Work Plan for Claude Code.
