# Work Plan for Claude Code is now Claude Code Plus

This is the last version of Work Plan for Claude Code (`xnervwang.claude-code-extras`). It installs [Claude Code Plus](https://marketplace.visualstudio.com/items?itemName=xnervwang.claude-code-plus) (`xnervwang.claude-code-plus`), which does everything this extension did and takes over your settings, pins and colors.

This version does nothing else. You can uninstall it.
